## Mathematics, data, and research references

The maintained implementation and tests use the Python standard library, with no
third-party runtime or test packages. Mathematical sources and independent
implementations are credited in README.md. Referencing a paper is not a license
to copy its prose, code, tables, or figures.

Optional Smirnov coefficients come from Austin R. Benson and Grey Ballard's
fast-matmul repository (BSD-2-Clause). The importer pins their source and checksum
and embeds the full upstream notice in the converted JSON. Optional AlphaEvolve
coefficients come from Google DeepMind's alphaevolve_results (Apache-2.0). Those
downloads and reference snapshots live in ignored `Background Research/`, not in
the source distribution. If distributing them or derived coefficients, include
their license and applicable notices and describe modifications. See
[third-party notices](THIRD_PARTY_NOTICES.md) and the README source bibliography.

Locally downloaded reference-only or unlicensed material, including the LITA
reference coefficients and Unity reference source, must not be added to a public
release without suitable permission. An ignored file is not license clearance.
