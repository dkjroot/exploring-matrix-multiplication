# Interior CW parts and original run evidence, 15 October 2026

This selected record preserves useful reusable parts and original observations
outside the ignored `outputs/` directory. It establishes no improved exponent.

The exact experiment considers 2,048 coordinate candidates for each of three
interior components of CW₂ squared and for each component's square: 12,288
attempts. The base sectors recognize 23, 23 and 22 candidates in those prefixes;
two recovered parts per base sector are retained. Their shapes are (2,1,2),
(1,2,2) and (2,2,1), with four data products apiece after paid finite recovery.
Each first retained witness also squares to a 16-product part. The three fresh
square-search prefixes recognize no additional parts. The tenth library entry
combines the three orientations from separate source copies into a verified
4-by-4 matrix recipe with 64 products and exponent three, equal to classical
cost. Search misses do not rule out other restrictions or general linear maps.

- `parts.json`: the original reloadable ten-part library, with exact rational
  factors, coordinate witnesses, source parameters, provenance, recovery events
  and execution counts. Copied from
  `outputs/construction_2026-10-15_141107_730936/parts.json`.
- `measurements.json`: the original small combined-suite arithmetic data,
  including its embedded exact and floating diagnostic reports. Copied from
  `outputs/2026-10-15_140812_888170/measurements.json`. The selected sizes were
  two and four, cutoff one, with Naive and Strassen plus generated recipes.
- `source-suite-manifest.json`: the original manifest of that passed 22-stage
  suite, preserving settings, setup measurements, source fingerprints and stage
  outcomes. Its relative artifact paths describe the original output tree;
  the complete generated HTML/certificate tree is not archived here.
- `file-sha256.json`: fingerprints of the three files above. These copies were
  preserved byte for byte; measurements and historical source hashes have not
  been relabelled as observations of a later source version.

The two original runs are distinct: the focused construction regenerated the
library after explicit source-parameter metadata was added; the small suite
supplies its own earlier source fingerprints and observations. The original
203-test regression run passed; a complete rerun of those tests is comparatively
slow and is not required merely to load this library.

## Reproduction and use

From the repository root, Python 3.10 or later and the standard library suffice
for this CW experiment. No ignored external coefficient downloads are needed.

```
python -m matrix_multiplication.constructions cw-interior --certificate
python sweep.py --sizes 2 4 --cutoffs 1 --algorithms naive strassen --cw-parameters 2 --cw-powers 2 --search-steps 50 --search-restarts 1 --pair-trace-limit 10 --projection-cycles 2
```

These commands create fresh dated output trees. The exact parts, matrix
identities and arithmetic budgets are reproducible with the same implementation
and parameters. Dates, elapsed times, Python allocation peaks and source-file
hashes need not match the original captures. Losing those original observations
cannot be repaired by substituting a new run. Broader sweeps involving
AlphaEvolve or Smirnov require the separately documented coefficient importers.

Load the selected library directly, without an `outputs/` directory:

```python
from matrix_multiplication.recipe_parts import load_parts, recombine_parts

parts, provenance = load_parts("reports/2026-10-15-interior-cw/parts.json")
left, left_evidence = parts[0]
right, right_evidence = next(part for part in parts if part[1]["shape"] == [1, 2, 2])
combined, shape = recombine_parts(left, left_evidence["shape"], right, right_evidence["shape"])
```

Loading checks every matrix coefficient and the executable product count. Source
maps remain derivation evidence: replaying them additionally requires rebuilding
their exact source tensors. See CONSTRUCTIONS.md for these boundaries and the
credited CW mathematical sources. The maintained implementation is GPL-3.0;
the source independently constructs these rational parts.

## Audit of ignored Python files

All 98 `check_certificate.py` files present at this audit were byte-identical
copies of `matrix_multiplication/certificate_checker.py`, generated by
`certificates.write_bundle`. They contain no unique implementation.

The other three scripts were scratch work:

- `fringe-diagnose.py` compares boundary counts already covered by
  `tests/test_fringe.py`, `tests/test_composition.py` and independent budgets.
- `update-fringe-docs.py` is a one-time text-replacement patch whose resulting
  source and documentation edits are already outside `outputs/`. It should not
  be rerun against the edited files.
- `rebuild_line_controls.py` renders one named historical report and a synthetic
  preview using maintained reporting, interactivity and suite-panel functions.
  The line-control behavior is covered by `tests/test_projection_ranges.py`.
  Its hard-coded scratch invocation is not a unique rendering implementation.

Older routine reports, screenshots and logs have not been selected for archival
publication. Their particular historical observations are not reproducible byte
for byte, but no stronger algorithm or unique research construction was found
only in them. No ignored output was deleted during this audit. Before a novel
result or historical comparison depends on a future run, promote its evidence
and any necessary source snapshot outside `outputs/`.
